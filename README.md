# Buscador de palabras

## Descripcion

Este programa permite buscar una palabra dentro de los archivos
de una carpeta especifica o de todo el sistema de archivos.

## Requisitos

- Sistema operativo Linux o macOS.
- Bash.
- Git.

## Uso

Para buscar una palabra dentro de una carpeta:

./buscador.sh palabra /ruta/de/la/carpeta

Para buscar una palabra sin especificar una carpeta:

./buscador.sh palabra

## Argumentos

- Primer argumento: palabra que se desea buscar.
- Segundo argumento (opcional): carpeta donde se realizara
  la busqueda.

El programa acepta un maximo de dos argumentos.
